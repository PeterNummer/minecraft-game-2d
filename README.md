# 🎮 Minecraft Game 2D

Ein kleines Minecraft-inspiriertes 2D-Browserspiel.

## 🤖 Hinweis zur Entwicklung

Dieses Projekt wurde mit Unterstützung von KI erstellt.
Die Spielidee und Anpassungen stammen vom Entwickler.

## 🕹️ Steuerung

- WASD oder Pfeiltasten – bewegen
- Linksklick – Blöcke abbauen
- Rechtsklick – Blöcke setzen
- R – Spiel neustarten

## ⭐ Funktionen

- 2D-Minecraft-Welt
- Blöcke abbauen und setzen
- Gegner
- Leben
- Punktesystem
- Touch-Steuerung für Handy und Tablet

Viel Spaß beim Spielen! 🚀
