# ⛏️ Minecraft Game 2D

Ein kleines Minecraft-inspiriertes 2D-Browsergame, das direkt im Webbrowser gespielt werden kann.

## 🎮 Funktionen

- 🧱 Blöcke abbauen
- 🧱 Eigene Blöcke platzieren
- 🏃 Spielerbewegung mit WASD oder Pfeiltasten
- ⬆️ Springen
- 👾 Gegner
- ❤️ 3 Leben
- ⭐ Punktesystem
- 🎯 Zielpunkt für jedes Level
- 🗺️ 5 verschiedene Level
- ⚙️ Drei Schwierigkeitsstufen:
  - 🟢 Einfach
  - 🟡 Normal
  - 🔴 Schwer
- 💾 Spielstand speichern
- ▶️ Spiel fortsetzen
- 🗑️ Spielstand löschen
- 📱 Touch-Steuerung für Smartphones und Tablets
- 🖥️ Läuft direkt im Browser

## 🎯 Spielziel

Das Ziel des Spiels ist es, den **grünen Zielpunkt** am Ende des jeweiligen Levels zu erreichen.

Wenn der Spieler den Zielpunkt berührt:

1. Das Level ist geschafft.
2. Der Fortschritt wird gespeichert.
3. Der Spieler kommt zurück ins Hauptmenü.
4. Dort kann das nächste Level gestartet werden.

Es gibt **keine Münzen mehr als Spielziel**.

## 🗺️ Level

Das Spiel enthält insgesamt **5 Level**.

Mit jedem Level werden die Gegner schwieriger.

## 💾 Speichern

Der Spielstand wird automatisch im Browser gespeichert.

Gespeichert werden unter anderem:

- aktuelles Level
- Schwierigkeitsgrad
- Punkte
- Leben
- Blöcke

Der Spielstand kann über das Menü fortgesetzt oder gelöscht werden.

> Hinweis: Der Spielstand wird nur auf dem jeweiligen Gerät und im jeweiligen Browser gespeichert.

## 🎮 Steuerung

### PC

| Taste | Funktion |
|---|---|
| WASD | Bewegen |
| Pfeiltasten | Bewegen |
| Leertaste | Springen |
| Linksklick | Block abbauen |
| Rechtsklick | Block platzieren |
| 1–5 | Block auswählen |
| R | Level neu starten |
| ESC | Hauptmenü |

### Smartphone / Tablet

Auf Geräten mit Touchscreen werden automatisch Touch-Steuerungen angezeigt.
